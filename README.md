# minimalism_programming

Lessons to Remember for Preserving the Value of Programming Despite Changing Times





## 0. Don't be ashamed of rough results.
<img width="600" alt="image" src="https://github.com/user-attachments/assets/6833e64a-6598-4095-95f7-df87e2c59906" />

At first, everyone is clumsy.
Don't hide your advantage.

A good programmer won't scold you.

## 1. Minimize the use of language, but dig deep.
There are so many programming languages these days. Don't be scary.

Start by practicing a deep understanding of one thing.

## 2. You have to write code you can understand.
 <img width="600" alt="image" src="https://github.com/user-attachments/assets/c59a4718-414f-444c-b398-239050b2d0a3" />
 
Readable code forms the foundation of maintainable code.
  
## 3. Don't neglect learning even at the expense of productivity.
Improved productivity does not always lead to efficiency.

## 4. You can't do complex programming for long.
Simplify the structure, but design it with precision.

## 5. Don't trust the code, trust the logic.

If you trust the code, you will be betrayed; 

if you do not trust your logic, development will not happen.


## 6. AI chatbot is a chat-bot.
It's not a monster that swallows you.<br>
But It doesn't mean he's even a friend. <br>
A chat is just a chat.

Let's learn and compete.
